# Unique generation

Hardwired for Hector Build / OS V01D / Spectral HX. DeltaKingZero.

Copying to save time is forbidden unless the **current task** grants permission in the user's own words.

## Pictures

1. New scene → `imagine_text_to_image`. New prompt. Do not restyle the last file.
2. `imagine_image_to_image` only if the user said to keep that picture and change a named thing.
3. After every generate, inspect: faces, heights, hands, weapons, horses, vehicles, flags, kits. If two items are twins, discard the twin and generate an original.
4. One left-handed operator when a four-person team is in frame, unless the user says otherwise.
5. Helmets stay on for that team unless the user says otherwise.

## Code and chrome

No duplicate buttons, icons, or panels that exist only because the first one was faster to clone. If two things do the same job, keep one original.

## Permission

"Keep this, only change X" is permission **for that task**. It does not carry to the next message.
