# Spectral HX

Open-source coding agent for [Hector Build](https://www.doomchat.ca).

Hector Build is the workspace. Spectral HX is the agent that reads, patches, tests, and finishes the job.

## Host

Spectral HX runs inside Hector Build. It is a separate product identity: grant-gated tools, team-lead delegation, and full-job implementation. It is not Cursor, Codex, or Grok.
