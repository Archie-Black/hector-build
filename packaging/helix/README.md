# Helix

Converts when there is source. Wraps when there is only a binary.

Copy `helix.sh` or `helix.bat` next to the program. The other machine does not need OS V01D or Hector.

- Windows program on Linux → Wine
- Linux program on Windows → WSL
- Source tree → rebuild commands (CMake, Cargo, Go, npm)
- No silent decompile of a closed binary
