# Hector Build

Host intelligence. Grok is Hector’s assistant. Spectral HX is the coding floor.

## Windows install (WSL)

Unzip onto NTFS. Double-click `packaging\windows\Install.bat`.

That **installs with WSL**: runtime in Linux, app windows on Windows (Chrome/Edge). If WSL is missing it tells you to run `wsl --install`.

Shortcuts: **Hector Build** and **Spectral HX**.

Uninstall: `packaging\windows\Uninstall.bat`

## Linux install

```
bash packaging/linux/install.sh
hector-build
spectral-hx
```

Uninstall: `bash packaging/linux/uninstall.sh`

## Live / web

Open `/` for Hector. Open `/hx` for Spectral HX.
